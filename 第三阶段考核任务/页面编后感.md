# 页面编后感

这是第一次写HTML CSS JS  

写前端我还是觉得自己不太在行，脑袋里面没有内容，没有艺术细胞吧，导致做出来的页面非常的丑陋哈哈哈哈哈哈哈，也搞不清楚配色之类的很多东西。  

做这个页面真的体会到了多显示器的方便之处，我宿舍里面有一个显示器，然后我把我那个游戏本竖过来了，然后显示器上面，一边是html，一边是css，然后笔记本屏幕上面就是网页的实时渲染，真的好爽啊。就那种感觉我靠，简直了，顿时感觉自己买显示器花的钱好值。  

写网页的过程其实是挺有趣的，但是我实在是想不出要做什么，我是一个比较有个性的人，就不想照着别人的成品去模仿，导致做出来的东西好丑哈哈哈哈哈。
